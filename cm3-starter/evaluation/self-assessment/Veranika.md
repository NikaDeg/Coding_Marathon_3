# Project Reflection

## Code Quality and Functionality

The code is good and works as specified in the requirements list. However, I can see room for improvement.

## Challenges and How I Overcame Them

The main challenge was **lack of time**. In my opinion, there were too many tasks for a coding marathon, and we went 2-3 hours over the planned time. We overcame it by staying focused, dividing the work among team members, and communicating continuously.

## What I Learned

- **Working with different branches:** a great way to develop features in parallel without conflicts.
- **Communication:** the most important lesson of the project.
